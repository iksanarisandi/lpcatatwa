Aplikasi Catatan Keuangan Rumah Tangga Praktis

Mengelola keuangan keluarga itu gak mudah. Belanja dapur, tagihan listrik, uang sekolah anak, cicilan — semuanya harus dicatat biar gak bingung di akhir bulan.

Tantangan Keuangan Rumah Tangga

  • ❌ Banyak jenis pengeluaran yang harus diingat
  • ❌ Sibuk ngurusin rumah, gak sempat catat
  • ❌ Suami istri perlu sinkronisasi catatan
  • ❌ Sering lupa tagihan yang sudah dibayar

Solusi Praktis via WhatsApp

Dengan Catat Uang WA, ibu rumah tangga bisa catat pengeluaran sambil masak atau belanja. Cukup ketik di WhatsApp:

  • "Belanja pasar 150k" → tercatat
  • "Bayar listrik 200k" → tercatat
  • "Uang sekolah 500k" → tercatat
  • "saldo" → lihat sisa budget bulan ini

Kelola keuangan keluarga jadi lebih mudah!

Fitur untuk Rumah Tangga

  • ✅ Catat semua jenis pengeluaran keluarga
  • ✅ Scan struk belanja bulanan
  • ✅ Rekap pengeluaran per kategori
  • ✅ Dashboard web untuk review bersama
  • ✅ Edit dan hapus transaksi yang salah

Paket Starter untuk Keluarga

Paket Starter (Rp29.000/bulan) cocok untuk rumah tangga:

  • 120 teks per bulan (~4 catatan/hari)
  • 40 scan struk per bulan
  • Edit dan delete via web

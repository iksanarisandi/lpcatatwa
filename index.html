Pertanyaan yang Sering Ditanyakan

Bagaimana cara catat keuangan via WhatsApp? +

Cukup chat ke nomor Catat Uang WA dengan format sederhana, contoh: "20k jajan kopi" untuk pengeluaran atau "+2jt gaji" untuk pemasukan. Sistem akan otomatis mencatat transaksi Anda.

Berapa harga berlangganan Catat Uang WA? +

Mulai dari Rp9.000/bulan untuk paket Lite (200 teks, 20 struk). Ada juga paket Starter Rp19k, Premium Rp39k, dan Pro Rp89k dengan fitur unlimited.

Apakah bisa export laporan ke Excel? +

Ya, paket Premium dan Pro memiliki fitur export laporan ke format CSV yang bisa dibuka di Excel untuk analisis lebih lanjut.

Apakah ada dashboard web untuk melihat transaksi? +

Ya, semua paket berbayar memiliki akses ke dashboard web untuk melihat detail transaksi, edit, dan hapus catatan.

Bagaimana cara pembayaran? +

Pembayaran bisa dilakukan via Transfer Bank atau QRIS. Setelah pembayaran dikonfirmasi, akun Anda akan langsung aktif dalam 1 menit.
